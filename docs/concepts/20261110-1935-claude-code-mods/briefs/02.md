## New evidence (not in any file — cite in `data-evidence`)

Stability research (web, 2026-11-10):
- Mods shipped in 2.1.287 on 2026-10-01 → ~6 weeks old. Docs carry no "experimental" label, but the
  claude.dev tutorial says "The API can change between releases"; version gates at .289/.290/.292/.293/
  .296/.299/.300/.318 — about one API addition every 1–3 releases, all additive so far, no documented
  hard break found (changelog not fully read).
- Anthropic can switch installed mods off remotely; a failing mod is skipped silently (debug log only);
  hook time limit 10 s.
- Open issue #105936 (2026-10-29, area:desktop): in the Desktop Code tab "Turn them on" → mod never loads,
  same mod loads in terminal with --plugin-dir. #102330 (Windows, consent prompt loops). Desktop consent
  path is the weakest area. No crash reports found.
- Surfaces: CLI and Desktop Code tab full; WSL none; `claude -p` hooks only, no drawing; cloud: hooks only
  if the plugin reaches the session, nothing draws.
- One plugin MAY hold both classic `hooks` and `modules` in hooks/hooks.json (docs reference + admin page:
  classic hooks are not deprecated). → removes the version-skew risk of a separate companion plugin.
- No API starts a new Claude Code session. `$.prompt.submit` starts a turn in the current session;
  `$.prompt.fill` puts text in the input box; `turn.step` can set model/effort per request.
- Issue #100083: a fork cache miss (30k context: 10k read, 19k written) under a specific condition.

Own spike (this session, scratchpad, not in repo):
- `claude plugin validate` on a plugin with classic hooks + a module: passes.
- `claude plugin test` runs engine-backed, deterministic tests of a mod (2 tests green: status on
  session.start, one fork ping scheduled after turn.complete); event shapes are checked strictly.
- Version skew on this machine: Desktop engine 2.1.321, `claude` CLI on PATH 2.1.302.
- `$.model.fork` doc (types): re-sends "the main thread's last request (its model, system prompt, tools,
  messages)" → same prefix; setting a different `effort` can force a full cache write → never set effort.

Red team (adversarial review of the round-1 plan, with repo file:line):
- CRITICAL paste rewrite: Haiku excerpt is non-deterministic; `ss.run.task` would restore the excerpt
  instead of the real /do-run task (`ss.run.task.js:7-16`), `prompt.run.contract.js:7-18` reads prompt
  text. → deterministic head+tail + file path, never for /do-run, AUTOSTART, `<command-name>` prompts.
- CRITICAL card: `stop.flow.guard` is a quality gate (validation owed, undeclared background work,
  wrong claims; `stop.flow.guard.js:11-31`) → must stay the only authority; mod only draws a card the
  guard accepted.
- CRITICAL stand-down marker races/stales at SessionStart; shell hooks cannot read `$.store` → marker
  keyed by session_id + heartbeat + version, default "hooks run".
- CRITICAL cache ping might not hit the cache → disable on first ping if cache_read < ~95 % of context.
- HIGH title gets two writers (readers parse `custom-title` transcript entries: `session-title.js:12-22`,
  `perm.approval.watch.js:46-52`) → spike whether a mod rename writes that entry; one writer per turn.
- HIGH guard fast path skips dispatcher bookkeeping (`dispatch.js:18-25`), gain only milliseconds → drop.
- HIGH tool-output rewrite can hide the failing test → deterministic only, exempt test/git/CI commands.
- HIGH ping side effects: night pings open a 5-h window, count toward the weekly limit, many open
  Desktop sessions could each ping → machine-wide cap, never open a new 5-h window, cancel on input.
- HIGH two budget sources (`budget.js:20-50` vs session.measure) → mod writes into usage-live.json.
- MEDIUM notices as toast lose the model-visible restart hint (`ss.plugin.update.js:98`) → keep hook
  text, add toast. MEDIUM reload resets module vars → timers in `$.state`, idempotent. MEDIUM concept
  watchers wake Claude by exiting (`concept-watch.js:17-20`) → spike whether `$.prompt.submit` can wake.
  MEDIUM vitest only picks `*.test.js` (`vitest.config.mjs:24`) → add `claude plugin test` to CI.
- Verdict table: SAFE NOW (display only, hooks unchanged): sound/toast, agent fleet pane, ship/CI pane,
  budget+context band (same source), branch-hygiene display, notice toasts as extra. SPIKE FIRST:
  titles, cache keep-alive, concept timers, recap (also a fork), branch side-session button, tool-output
  redirect (deterministic). DROP: Haiku paste rewrite, Haiku tool-output excerpts, guard fast path,
  any stand-down of stop.flow.guard or the guards.
