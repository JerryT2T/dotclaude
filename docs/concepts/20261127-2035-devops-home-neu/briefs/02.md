## What round 2 shows

**Three designs, all built on d3 Statuskopf, varying ONE thing: the head card's content** ("was ist die wichtigste
Info oben?"). Everything else is IDENTICAL across the three designs (same body, same settings list, same tutorial).
Same pages, same order, same `data-nav-label`s in all three: `Übersicht`, `Einstellungen`, `Projekt aus`, `Erster Start`.
nav-labels of designs: bare names, no letters/numbers. Motto/traits/icon/color per design (traits = genuine
differences of the head only). Variant copy: name the thing first.

Head variants (each keeps the ⏻ power button top right and the state line "● An · überall"):
1. **"Budget-Kopf"** — head shows the budget as bars that look like the band's bars: track `#2b2d3a`, elapsed-time fill
   `#4a5384` (lilac), a 3 px vertical usage marker (white = im Plan, `#e6c36a` = knapp, `#e07a7a` = drüber) and the reset
   watermark inside the bar right-aligned in `#7d84a8` ("4 d 19 h"); label left "Woche", "5 h" or "Fable" as the band
   shows them (example: Woche 54 % at 61 % elapsed, Fable 31 %). Rounded 5 px, 12 px tall.
2. **"Wartet-Kopf"** — head leads with what waits for you: big "2 warten auf dich" + primary "Öffnen" (jumps to the
   longest waiting session); budget below as ONE compact band-style bar (Woche).
3. **"Tempo-Kopf"** — head leads with one verdict sentence on the pace: "Im Plan · 54 % verbraucht bei 61 % der Woche"
   with one wide band-style Woche bar, plus a quiet health dot "Hooks ✓" next to the state line.

Shared body (identical in all three):
- Tabs as underline tabs (as d3) "Übersicht  Einstellungen"; right of them: 🛏 icon button and ↻ — tooltips via
  `data-tip` (never `title`): 🛏 "PC ausschalten, sobald keine Sitzung mehr arbeitet", ↻ "vor 4 s aktualisiert".
- Session status as one row of ACTION chips: emoji + count + verb, e.g. "👉 2 Öffnen", "⏳ 3 Öffnen", "🟩 5 Archivieren",
  "🧹 4 Aufräumen". One neutral chip style (no colour coding per state — user found colours confusing); a chip with 0
  is shown as plain dim text without verb (info, not clickable). Clear visual rule: clickable = chip with border and
  verb; info = plain dim text.
- No "Älteste: …" line.
- Projekte as a list; each project's state chips are small clickable chips (emoji + count) that open the newest
  session of that state; "＋ Batch" right; "→ Batch" when a batch runs.
- Einstellungen tab in d2 list style. Groups: "Allgemein" (Browser › Microsoft Edge; **Ausgabestil › Quiet** — NEW
  separate row, independent of devops on/off), "Claude-Projekte" (Threads starten › Lokal zuerst; Ausnahmen › 0 von 5;
  Voraussetzungen › 1 ✓ · 4 offen; ⧉ Textblock kopieren), "Statistik · 7 Tage" (3 rows + "Alle 6 Werte ›"),
  "Hilfe" (Einführung erneut zeigen ›). Footer "devops 0.411.1". No devops on/off rows in this tab (the ⏻ owns it).
- "Projekt aus": head in off state (grey, "○ Aus · in dotclaude") with the ⏻ menu open: "Ausschalten für" ·
  Diese Sitzung · Projekt dotclaude ✓ · Alle Projekte · separator · **Einschalten** (links back to Übersicht).
  Body dimmed. Improvement pin as above.
- "Erster Start": the Übersicht with a coach-mark overlay (semi-transparent dark scrim over the pane, one highlighted
  element with a ring, a callout card "1 von 4 · Wozu devops Home?" short purpose text, buttons "Überspringen" and
  "Weiter"). Show step 1 = purpose. The other steps are listed as dots only.

Click-dummy wiring (`data-screen-link`): tabs switch Übersicht/Einstellungen; ⏻ → "Projekt aus"; "Einschalten" →
Übersicht; "Weiter"/"Überspringen" on "Erster Start" → Übersicht; "Einführung erneut zeigen" → "Erster Start".

Annotations: 3–5 per design, ids prefixed with round: `r2-d1-s1-a1` etc. (design ids: use `d1`,`d2`,`d3` as
